## Platform

## Users

Developers use the existing toolkit to format, convert, inspect and debug data and integrations. This audience is established by the repository's catalog and product copy.

## Product Purpose

Keep useful developer utilities together with explicit local processing and network boundaries. Version 2.0.0 adds the 24 capabilities and 18 tool extensions tracked in the acceptance ledger, with separate clean-production validation.

## Operating Context

The product is an existing Next.js application with canonical category/tool URLs, browser persistence, a PWA and a self-hosted Node container. Version 2.0.0 also includes a packaged desktop edition and authenticated localhost connectors. Desktop and browser storage profiles remain separate.

## Capabilities and Constraints

The full acceptance list is in `docs/capability-expansion-status.json`. Preserve existing saved data, working tools, light/dark readability and canonical routing. Do not commit or push. New interfaces extend the established tool workspace rather than replace its identity.

## Accessibility and Inclusion

The user selected English, Hindi, Spanish, French, German, Japanese, Chinese and Arabic. Arabic requires right-to-left layout. Preserve keyboard operation, accessible labels and responsive behavior.

## Evidence on Hand
