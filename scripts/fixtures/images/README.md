These original test images are generated by `scripts/generate-image-fixtures.py` using Pillow. Their camera, artist, timestamps and GPS fields contain fixed public fixture values. They contain no user photographs or private metadata.

The files exercise progressive JPEG, CMYK/Adobe JPEG, PNG text/EXIF/ICC, WebP EXIF/XMP/ICC, animated WebP, TIFF and AVIF. Regeneration requires Pillow 12 with WebP and AVIF codecs. Set `EXPANSION_IMAGE_CODEC=true` when running the image-metadata suite to independently compare decoded pixels and all animation frames through Pillow.
