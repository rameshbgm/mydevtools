The header's language selector is a globe plus a two-letter language code, directly beside the favorites star. Clicking opens a menu with full language names and the selected language highlighted. Keyboard opening, selection and Escape are supported. It stores a single global `mydevtools-language` preference, shared across projects in the same browser profile and visible in Memory & Storage. The browser and desktop profiles are separate. There is no translation service, cookie, outgoing translation request or automatic upload of tool input. Unsupported or malformed preference values fall back to English. If storage is unavailable, the current session still changes language and displays a persistence notice.

`LanguageProvider` updates React context without a locale key, route navigation or page reload. Changing languages retains mounted tool state and drafts. Other same-origin windows subscribe to language changes through storage events. Ant Design receives the matching component locale and Arabic direction. The first-paint root script restores the stored language and direction; initial server-rendered content remains English so canonical tool URLs and existing static routes stay unchanged.
