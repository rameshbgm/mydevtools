## References and correctness

Curated reference pages now distinguish formal RFC maturity, replacement links and deployment advice. Updates include TLS 1.3 RFC 9846, the DMARC RFC 9989–9991 family, IPv6 documentation/dummy ranges, port 465 implicit TLS, YAML media type RFC 9512, WCAG 2.2 contrast and the documented TOON 4.4 syntax subset. The [source catalog](../src/lib/reference-sources.json) records primary links, scope, review dates and review intervals. Prices are dated snapshots; individual model rates and context limits retain their exact displayed values.

Import and file-read repairs preserve concurrent saved changes and cancelled selections. Spreadsheet export rejects numeric values Excel cannot preserve and explains how to quote them as text. File-vault imports validate canonical Base64 and declared byte counts before saving. Certificate copy actions report success only when the shared clipboard operation succeeds. XSD help and results explicitly describe limited XML/root/namespace checks; they do not claim datatype, cardinality or full schema validation. Application-authored diagnostic prose translates while original parser/browser messages and embedded data remain unchanged.

## Help, privacy and documentation

Every registered tool has Learn More guidance, including curated help for 21 newer pages. All 20 network-capable pages show a detailed, initially collapsed disclosure with destinations, sent fields, handling and source links. Direct browser requests, managed proxy requests, authenticated localhost services and external model downloads have distinct explanations. See [tool guidance](tool-guidance.md).

English, Hindi, Spanish, French, German, Japanese, Simplified Chinese and Arabic preserve user-entered data, code, raw results and stable protocol identifiers. Arabic uses RTL navigation with explicit isolation for machine values. See [localization](localization.md).

Workspace tabs allow double-click/F2 rename and confirmed permanent removal through their corner X; Personal remains protected. Manage projects also provides recoverable deletion and restoration. The limit is ten active workspaces including Personal. See [storage and projects](storage-and-projects.md).

The [desktop edition](desktop.md) bundles its own production runtime and local editor/database/inference assets. Native connectors need an explicitly enabled authenticated localhost runtime on the web; desktop access is supplied internally. Network features and uncached semantic-search model weights still need connectivity.

## Verification scope

Final build 72 passes all 92 suites on both the main source and a fresh locked-install workspace, explicit TypeScript checks, zero-error lint and both optimized builds (173 pages). HTTP checks cover all 147 canonical tool pages and discovery resources. The Node 24 container and actual owned SQL/S3/gRPC/mock fixtures pass. The macOS arm64 archive passes asset/runtime/ASAR/fuse/signature/archive checks; it is ad-hoc signed and has not been notarized, installed or published. See the [durable validation record](v2.0-validation.json).

The current request excludes browser/UI verification. Page-level source, actual component callbacks, independent format/crypto parsers, TypeScript and production builds provide the evidence for this batch. Download-handler byte checks do not establish browser file delivery. Chrome-installed PWA removal and earlier browser file-transport limitations remain documented in the capability ledger; no workaround or removal is claimed.
